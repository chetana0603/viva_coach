# User Guide

## Teacher Workflow

### 1. Create a Teacher Account
Use the admin setup script to create the first teacher account.

### 2. Import Students
Go to the teacher student management area and import a roster CSV containing:
- `register_number`
- `full_name`
- `email`
- `department`
- `section`

### 3. Create an Exam
Create a pre-test, post-test, or project viva exam. Configure:
- registration window
- exam window
- duration
- question count
- concepts in scope
- study group tag (for linked pre/post tests)

### 4. Approve Registrations
Approve student registrations before the exam begins.

### 5. Review Results
After the exam closes, open the evaluation views to review student performance and export results.

## Student Workflow

### 1. Register an Account
Students register with an eligible register number and wait for teacher approval.

### 2. Join an Exam
Students register for an exam from the dashboard once the registration window is open.

### 3. Take the Exam
Students start the attempt, answer adaptive questions, and submit when complete.

### 4. Review Feedback
Depending on the exam type, students may see explanations and breakdowns after each answer or after submission.

## Project Viva Workflow
Students can:
1. Upload a report or paste content.
2. Analyse the submission.
3. Review generated study cards.
4. Generate a project-based question pool for the viva.
